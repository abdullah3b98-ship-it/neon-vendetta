# NEON VENDETTA — ثأر النيون

An original top-down neon action game for the browser (plain JS + Canvas, procedural art and music). Keyboard/mouse, Xbox and PlayStation (DualShock 4 / DualSense) controllers supported. 10 original masks with abilities, pixel-art characters.

Play: https://abdullah3b98-ship-it.github.io/neon-vendetta/
